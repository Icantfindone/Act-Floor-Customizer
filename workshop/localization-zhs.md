# Steam 创意工坊 · 简体中文标题与描述

Steam 没有给模组条目提供「按语言分开的标题/描述」的接口，上传器（ModUploader）只能写基础语言。
所以 `workshop.json` 里放英文（基础语言），**简体中文这一份要在网页上粘贴一次**。

## 操作步骤

1. 打开 https://steamcommunity.com/sharedfiles/filedetails/?id=3843992717 → 右侧「编辑标题与描述」。
2. 语言下拉框选 **简体中文**（Simplified Chinese）。
3. 标题填下面「标题」那一行；描述填「描述」里 BBCode 全文（不要加代码块反引号）。
4. 点「保存」。

粘贴后，中文用户在创意工坊看到中文，其他用户看到英文基础版。

---

## 标题

```
每幕自定义加层
```

## 描述

```
[h1]每幕自定义加层[/h1]
在游戏内给第一、二、三幕分别增加 0～30 个普通楼层，并通过 BaseLib 的模组配置页调节。

[h2]功能[/h2]
[list]
[*]三幕分别设置，每个 0～30 层，0 = 保持原版长度。
[*]问号、商店、休息点、精英配额按地图长度近似等比增加，普通战斗池同步变长。
[*]加长后的地图会按原版行距绘制并纵向拉伸，房间不再挤在一起；羊皮纸背景同步加长。
[*]中英文界面跟随游戏语言，模组列表里显示的名字也会自动切换成中文。
[*]支持多人：层级以房主的设置为准，其他人自己的数字不生效。
[/list]

[h2]安装[/h2]
订阅本模组，同时订阅前置 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3737335127]BaseLib[/url]。启动游戏后在模组列表启用并重启。

[h2]设置[/h2]
主菜单 → BaseLib 的模组配置页面 → 每幕自定义加层。三个滑块分别对应三幕。设置会在下一局生效，已经开始的局不会重画地图。

[h2]注意事项[/h2]
[list]
[*]多人游戏由房主在大厅开局时把三个数字发给所有人，客户端会忽略自己本地的设置。房主若在局中改数字，只影响下一次新开的局。
[*]同时使用「地图增强」等会穷举所有路线的模组时，建议每幕不超过 15 层。实测 46 行地图有约 5000 万条路线，会让路线分析卡死。
[*]Blitz 模式不适用。
[*]不兼容会改写战斗池或地图结构的其他模组，需自行测试。
[/list]
```
