# Steam 创意工坊 · 简体中文标题与描述

Steam 上传器（ModUploader）的 `workshop.json` 只有一个标题和一个描述，写的是**基础语言（英文）**。
按语言的标题/描述存的是同一个条目的「语言版本」，只能通过 `ISteamUGC::SetItemUpdateLanguage` 写入。

**当前状态：中文版已发布**（2026-11-23），中文用户在创意工坊看到中文，其他用户看到英文基础版。

## 怎么更新的

工具在本仓库 `workshop/localizer/`（需要引用游戏自带的 `Steamworks.NET.dll`，路径写在 csproj 的 `Sts2Dir` 里）：

```
cd workshop\localizer
dotnet build -c Release
cd bin\Release\net9.0
.\WorkshopLocalizer.exe "..\..\..\..\localization-zhs.md" "0.8.2：藏宝图红叉修正"
```

要求：Steam 客户端已登录、以 `danger-full-access` 运行。下面两个代码块会被工具自动读取
（第一个是标题，第二个是描述），所以改文案只要改这个文件再跑一次。
必须使用游戏目录里的 `steam_api64.dll`（300392 字节）；上传器自带的那份（317080 字节）版本较旧，
会在 `CSteamAPIContext.Init()` 抛 `EntryPointNotFoundException: SteamAPI_ISteamClient_GetISteamGameSearch`。
csproj 已自动拷贝正确的那份，不需要手动复制。

也可以不走工具，直接在网页上手动粘贴同样的内容：条目的「编辑标题与描述」→ 语言选 **简体中文** → 粘贴 → 保存。

## 标题

```
每幕自定义加层
```

## 描述

```
[h1]每幕自定义加层[/h1]
在游戏内给第一、二、三幕分别增加 0～50 个普通楼层，并通过 BaseLib 的模组配置页调节。

[h2]功能[/h2]
[list]
[*]三幕分别设置，每个 0～50 层，0 = 保持原版长度。
[*]另外四根滑块设置问号、商店、休息点、精英各自占多少百分比，剩下的都是普通战斗；四个都是 0 时保持原版比例。
[*]问号、商店、休息点、精英配额按地图长度近似等比增加，普通战斗池同步变长。
[*]加长后的地图会按原版行距绘制并纵向拉伸，房间不再挤在一起；羊皮纸背景同步加长，上下两个卷边保持原版大小，中间按原版宽度分段拼接，纸面宽度和卷边一致，底边固定不动。
[*]中英文界面跟随游戏语言，模组列表里显示的名字也会自动切换成中文。
[*]支持多人：层级和房间比例都以房主的设置为准，其他人自己的数字不生效。
[*]每 N 行额外多一排宝箱（默认 7，0 关闭），从原版那排宝箱往上一路数，所以加层之后也能多拿宝箱。
[*]藏宝图那一幕和金色罗盘地图也会按设置的层数生成，不再固定原版长度。
[/list]

[h2]安装[/h2]
订阅本模组，同时订阅前置 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3737335127]BaseLib[/url]。启动游戏后在模组列表启用并重启。

[h2]设置[/h2]
主菜单 → BaseLib 的模组配置页面 → 每幕自定义加层。页面分成三个可以折叠的分组：[b]每幕层数[/b]（三根 0～50 的滑块）、[b]宝箱行[/b]（每隔多少行加一排宝箱）、[b]房间比例[/b]（问号 / 商店 / 休息点 / 精英的百分比，0 = 保持原版；加起来超过 100 会按比例缩小）。设置会在下一局生效，已经开始的局不会重画地图。

[h2]注意事项[/h2]
[list]
[*]多人游戏由房主在大厅开局时把三个数字发给所有人，客户端会忽略自己本地的设置。房主若在局中改数字，只影响下一次新开的局。
[*]超过 20 行的地图会跳过原版的「重复路径修剪」，因为那一步要枚举所有路线；46 行的地图路线数是天文数字，藏宝图那一幕换地图时正是它把游戏卡死的。地图生成本身已保证每个点都能走到 Boss，所以可能出现两条看起来一样的路径。
[*]Blitz 模式不适用。
[*]藏宝图那一幕里，特殊宝箱所在的那一行只保留它一个宝箱；同一幕其它宝箱行不受影响。
[*]宝箱行和房间比例只对真正加了层的幕生效，原版长度的幕完全不变。
[*]房间比例里精英不低于第 6 行、休息点不低于第 5 行且不进最后三行、同类特殊房间不上下相邻，每行最多一个商店/精英/休息点，精英最多 14 个。
[/list]

[h2]已知兼容问题[/h2]
[list]
[*]会穷举所有路线的模组（「地图增强」等）：每幕建议不超过 15 层。实测 46 行地图有约 5000 万条路线，它的路线分析会卡死。
[*]会绘制大尺寸小地图总览的模组：长地图上要重建很大的预览图，会明显掉帧（实测 46 行约 6 FPS）。地图界面卡就关掉小地图总览，或者降低层数。
[*]会改写战斗池或地图结构的其他模组可能与加长地图冲突，需自行测试。
[/list]
```

- 这个文件里 `## 标题` 和 `## 描述` 下面各有一个代码块，`workshop/localizer` 按这两个标题取内容；改完用本地化工具发布即可。
