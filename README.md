# Act Floor Customizer

Slay the Spire 2 mod: up to 50 extra floors per act, the map stretched to keep vanilla spacing, a
row of treasure rooms every N rows, a configurable room mix, and host-authoritative co-op.
每幕最多加 50 层，地图按原版间距纵向拉长，可加宝箱行、可调房间比例，联机时以房主的设置为准。
